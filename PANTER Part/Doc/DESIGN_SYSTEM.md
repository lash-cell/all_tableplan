## 1. Design Direction (อนุมัติแล้ว)

**ที่มา:** ภาพอ้างอิง 3 ภาพ (แดชบอร์ดคอร์สสีพาสเทล, แดชบอร์ดสต็อก, แอปเรียนภาษา)
**ที่ผู้ใช้เลือก:** สีหลักทีล/มิ้นต์ · ธีมสว่างอย่างเดียว · motion ระดับปานกลาง · แถบเมนูข้างสีขาว

**บุคลิก:** อบอุ่น อ่านง่าย เป็นมิตร แต่ใช้งานจริงจังได้ (เป็นเครื่องมือจัดตาราง ไม่ใช่เกม)

| หลักการ | เหตุผล | นำไปใช้ |
|---|---|---|
| พื้นครีมอ่อน + การ์ดขาวมุมโค้ง | ให้ความรู้สึกนุ่มแบบรูปอ้างอิง ลดความล้าสายตาเมื่อดูตารางนาน | `--color-canvas`, `--radius-lg` |
| สีพาสเทลบอก **ความหมาย** ไม่ใช่ตกแต่ง | ตารางเรียนมีหลายประเภทวิชา แยกด้วยสีอ่านได้ทันที | tint ต่อประเภทวิชา (ดู §3 TimetableBlock) |
| สีเน้นเดียว (ทีล) | กันหน้าตาแตกเป็นหลายธีม ปุ่มหลักเด่นชัด | `--color-primary-700` |
| ตัวเลขใหญ่ หัวข้อทักทาย | เห็นสถานะภาพรวมทันที (ภาระครู คาบครบ) | `--text-3xl/4xl` + Prompt |
| Motion ช่วยบอกสถานะ ไม่ใช่โชว์ | งานคือ "จัดตารางแล้วเห็นผล" การเคลื่อนไหวควรเล่าว่ากำลังทำอะไร | ดู §3 และกฎ Motion |

**ไม่ทำ:** ธีมมืด · ตัวละคร/ภาพประกอบหนัก (ตัวมาสคอตแบบรูป 3) · ไล่สีเต็มพื้นหลัง · เอฟเฟกต์ที่ทำให้หน้าช้า

**กลุ่มผู้ใช้/อุปกรณ์:** ผู้จัดตารางบนคอมพิวเตอร์เครื่องเดียว · ไม่มีหน้าสำหรับนักเรียนหรือการเข้าจากอุปกรณ์อื่น
**เป้าหมายการเข้าถึง:** WCAG 2.2 AA

- Shadow: `shadow-1` (ขอบนุ่ม) · `shadow-2` (hover/การ์ดลอย) · `shadow-3` (dialog)
- z-index: base 0 · sticky 10 · sidebar 20 · dropdown 30 · dialog 40 · toast 50
- Breakpoints: sm 640 · md 768 · lg 1024 · xl 1280 · 2xl 1536

## 3. Components

สถานะทุกตัวต้องมี default · hover · focus-visible · active · disabled · loading (ถ้าไม่เกี่ยวเขียน n/a พร้อมเหตุผล)
Focus ใช้ `--focus-ring` เสมอ (วงขาว + วง primary-600) เห็นชัดบนทุกพื้น

### Button
| | ค่า |
|---|---|
| โครงสร้าง | ไอคอน(ไม่บังคับ) + ข้อความ · สูง 40 (md) / 32 (sm) / 48 (lg) · padding-x 16 · radius 12 |
| Variant | **primary** (พื้น primary-700 ข้อความขาว) · **secondary** (พื้นขาว ขอบ border-input ข้อความ primary-700) · **ghost** (ไม่มีพื้น) · **danger** (ข้อความ/ขอบ danger-ink) |
| hover | primary → primary-800 · secondary/ghost → พื้น primary-50 (150ms) |
| focus-visible | `--focus-ring` |
| active | ยุบ `scale(0.98)` 80ms |
| disabled | ลดความเข้ม + `aria-disabled` ห้ามใช้สีเทาจางจนข้อความอ่านไม่ออก (ยังคงอ่านได้ ≥3:1 ตาม WCAG ที่ยกเว้น แต่ใส่คำอธิบายเหตุผลถ้าสำคัญ) |
| loading | แทนไอคอนด้วย spinner หมุน 800ms เส้นตรง, ล็อกขนาดปุ่ม, `aria-busy` |
| Do | หนึ่งหน้ามี primary ได้ 1 ปุ่ม · Don't: ใช้ primary-500/600 เป็นพื้นปุ่มที่มีข้อความขาว |

### IconButton
สี่เหลี่ยมมน 40×40 (พื้นที่กดขั้นต่ำ 40) ต้องมี `aria-label` สถานะเหมือน Button ghost

### SearchField (pill)
สูง 44 · radius pill · พื้นขาว · ขอบ border-input · ไอคอนแว่นซ้าย · hover ขอบเข้มขึ้น · focus-visible วงแหวน + ขอบ primary-600 · disabled/readonly n/a (ไม่มีในแผน) · loading: ไอคอนเปลี่ยนเป็น spinner

### Card
พื้นขาว · radius 16 · `shadow-1` · padding 24 · ขอบ border (ตกแต่ง)
คลิกได้ → ใช้ `.tt-lift` (ยก 2px + shadow-2, 150ms) และต้องเป็นปุ่ม/ลิงก์จริงที่โฟกัสได้ · disabled: ลดความเข้ม · loading: Skeleton ในรูปทรงเดียวกัน
**Tinted Card:** พื้น tint-bg ข้อความ tint-ink สำหรับสรุปวิชา/กลุ่ม ไม่มีเงา

### StatTile
ไอคอนในกล่อง tint + ตัวเลข Prompt 40/600 + ป้ายกำกับ muted 14 · ไม่คลิกได้ (n/a hover/active) · loading: skeleton · ตัวเลขนับขึ้น 360ms ครั้งแรกที่ปรากฏ

### SidebarNav
กว้าง 96 · แต่ละรายการ: ไอคอน 24 + ป้ายกำกับ 12–14 แนวตั้ง · รายการที่เลือก: แถบสี primary-700 กว้าง 3 ด้านขวา + ข้อความ primary-700 + พื้น primary-50 · hover พื้น primary-50 · focus-visible วงแหวน · `aria-current="page"` · ต่ำกว่า md ย่อเป็นแถบล่าง

### PageHeader
คำทักทาย/ชื่อหน้า (H1 32) + คำอธิบาย muted + SearchField ใต้หัวข้อ

### Tabs / Segmented
ใช้สลับมุมมองตาราง: **กลุ่ม · ครู · ห้อง · วิชา** pill group, ตัวที่เลือกพื้น primary-700 ข้อความขาว, เลื่อนตัวเลือกด้วย transform 240ms `ease-standard` · ใช้ลูกศรซ้าย/ขวาเปลี่ยนตัวเลือก (role="tablist")

### Select / Input
สูง 44 · radius 12 · ขอบ border-input · error: ขอบ danger-ink + ข้อความใต้ช่อง + ไอคอน · label อยู่เหนือช่องเสมอ

### FileDropzone (หน้า Data)
กรอบประ border-input radius 16 · hover/dragover: พื้น primary-50 + ขอบ primary-600 (150ms) · มีปุ่ม "เลือกไฟล์" ทางเลือกด้วยคีย์บอร์ด · ระยะแรกระบุเฉพาะ `.xlsx` (CSV/PDF เป็นงานภายหลัง) · loading: แถบความคืบหน้า · error: Alert

### DataTable
หัวตารางพื้น surface-sunken ข้อความ strong 14/600 · แถวสลับพื้นไม่ใช้ (ใช้เส้นแบ่ง border) · hover แถวพื้น primary-50 · แถวที่มีปัญหา: ไอคอน + ข้อความ ไม่ใช้สีอย่างเดียว · เลื่อนแนวนอนได้ที่จอแคบ

### Badge / Chip
pill, 12/500, tint ตามความหมาย · ป้ายกฎ `R11` ใช้ tint-sky · ไม่คลิกได้ (n/a) ยกเว้นเป็น Filter chip (hover/focus/selected)

### StatusBanner (ผลการจัดตาราง)
| status | สี | ไอคอน | ข้อความหลัก |
|---|---|---|---|
| `feasible` | success | เครื่องหมายถูก | มีตารางที่ผ่าน independent checker |
| `searchLimit` | warning | นาฬิกา | ถึงขีดจำกัดค้นหา (ไม่ได้แปลว่าจัดไม่ได้) |
| `infeasible` | danger | สามเหลี่ยม | พิสูจน์แล้วว่าจัดไม่ได้ + สาเหตุ |
| `invalidInput` | danger | วงกลมอัศเจรีย์ | ข้อมูลไม่ถูกต้อง + รายการที่ต้องแก้ |
| `validationFailed` | danger | กากบาท | checker ไม่ผ่าน · เป็นข้อบกพร่องของระบบ ห้ามแสดงตาราง |
`role="status"` (feasible) / `role="alert"` (ผิดพลาด) · ทุกข้อความและสถานะมาจากผลของ server/engine ไม่คำนวณใน UI

### Generate progress
หน้า Generate แยกการตรวจ "Can this fit?" ออกจากการเริ่ม Generate · ระหว่างค้นหาแสดงเวลาที่ผ่านไปและ score ระหว่างปรับปรุงเมื่อมี · มี Cancel ขณะ run ทำงาน · ห้ามแสดงเปอร์เซ็นต์หรือลำดับ Plan/Act ปลอมถ้า server ไม่ได้ส่ง progress นั้น · แสดงสถานะเป็นข้อความด้วย (`aria-live="polite"`)

### ProgressRing / Bar
ค่าที่แสดงเป็นตัวเลขกำกับเสมอ · animate `stroke-dashoffset` 600ms ครั้งแรก · ถ้าไม่ทราบความคืบหน้า (กำลังค้นหา) ใช้ indeterminate (แถบเลื่อน) ไม่ใส่ตัวเลขปลอม

### TimetableGrid
**แนวนอน:** แถว = วัน (จันทร์–ศุกร์), คอลัมน์ = คาบ 1–11 · บล็อกหลายคาบกว้างหลายคอลัมน์ · คาบเกินที่ชั้นนั้นอนุญาตแสดงเป็นลายขีด · คอลัมน์ชื่อวัน sticky ด้านซ้าย (เลื่อนแนวนอนได้) · ช่องพักกลางวันแสดงป้าย "พัก" พื้น slate · ใช้ `role="grid"` + `aria-label` ระบุกลุ่ม/ครู/ห้อง · เข้าฉากไล่ทีละบล็อก `.tt-stagger` (ไม่เกิน 600ms) · เลื่อนแนวนอนได้ที่ <1024

### TimetableBlock
| ประเภท | tint | เงื่อนไข |
|---|---|---|
| วิชาสามัญ | lavender | `category=general` |
| ทฤษฎีแผนก | butter | `kind=theory` |
| ปฏิบัติ COM | mint | `roomNeed=COM` (หรือห้องที่ได้ COM*) |
| ปฏิบัติ LAB | peach | LAB* |
| กิจกรรม/ลูกเสือ | rose | `fixed` พฤหัส 6–7 |
| ล็อกตามโจทย์ | ไอคอนกุญแจเพิ่มบนบล็อก | `fixed` |

ในบล็อก: รหัสวิชา (12/500), ชื่อวิชา (14/600 ตัดบรรทัด 2 แล้วใช้ tooltip), ครู/ห้อง (12) · บล็อกยาวหลายคาบ = ช่องเดียวสูงหลายแถว · hover: ยก 2px + tooltip รายละเอียด · focus-visible วงแหวน · **เมื่อมีข้อขัดแย้ง:** ขอบ danger-ink 2px + ไอคอน ⚠ + สั่นครั้งเดียวตอนปรากฏ ไม่ใช้สีเดียว

### Skeleton
พื้น surface-sunken + shimmer เลื่อน 1.4s เส้นตรง · reduced-motion: ไม่เลื่อน คงพื้นนิ่ง

### Toast
มุมขวาล่าง · เข้า `tt-fade-up` 240ms · ออก 150ms `ease-exit` · หายเอง 5s (ผิดพลาดไม่หายเอง) · `role="status"`

### Dialog (ส่งออก Excel/PDF)
overlay ดำ 40% · กล่อง radius 24 shadow-3 · เข้า: fade + scale 0.96→1 ใน 240ms · ปิดด้วย Esc · โฟกัสถูกกักภายใน · คืนโฟกัสไปปุ่มเดิม

### Tooltip
พื้น text-strong ข้อความขาว 12 · หน่วง 300ms ก่อนแสดง · แสดงเมื่อโฟกัสด้วยคีย์บอร์ดด้วย

## 4. Layout

- **โครง 3 ส่วน** (เดสก์ท็อป ≥1280): SidebarNav 96 · เนื้อหากลาง (max 1200, padding 32) · Context Panel 320 (ว่างได้ ใช้แสดงบันทึกการจัดตาราง/รายละเอียดที่เลือก)
- **Grid:** 12 คอลัมน์ gap 24 · การ์ดสรุป 2–4 ต่อแถว
- **จังหวะแนวตั้ง:** ระหว่างส่วนใหญ่ 32 · ระหว่างการ์ด 24 · ภายในการ์ด 16 · หัวข้อกับเนื้อหา 12
- **การจัดวาง:** ชิดซ้าย ข้อความ ตัวเลขชิดขวาในตาราง

| ช่วงจอ | พฤติกรรม |
|---|---|
| ≥1280 | 3 ส่วนเต็ม |
| 1024–1279 | Context Panel ซ่อนเป็นลิ้นชัก |
| 768–1023 | Sidebar ย่อเหลือไอคอน · การ์ด 2 คอลัมน์ · ตารางเลื่อนแนวนอน |
| <768 | แถบเมนูล่าง · การ์ด 1 คอลัมน์ · ตารางเลื่อนแนวนอนได้โดยไม่ทำให้หน้าเลื่อนตาม · ไม่มีหน้าสำหรับนักเรียน |

ใช้ container เดียวกันทุกหน้า ห้ามหน้าใดกำหนดความกว้างเอง

## 5. Rules (บังคับ)

1. เอกสารนี้อยู่เหนือรสนิยมและความเร็ว
2. ห้ามใช้สี ระยะ ขนาดอักษร เงา z-index หรือ easing นอก token (ห้าม hex ดิบและค่า arbitrary ในคอมโพเนนต์ ให้ใช้ `var(--...)`)
3. ห้ามสื่อสถานะ/ความขัดแย้งด้วยสีอย่างเดียว ต้องมีไอคอนหรือข้อความ
4. ปุ่มหลักมี 1 ปุ่มต่อมุมมอง
5. Motion: animate เฉพาะ `transform` และ `opacity` · ไม่เกิน `dur-emphasis` · ห้ามวนซ้ำไม่จำกัดนอกจาก spinner/indeterminate/พัลส์ของขั้นที่กำลังทำ · **ต้องรองรับ `prefers-reduced-motion`** (token หดเหลือ ~0) · ห้ามกระพริบเกิน 3 ครั้ง/วินาที
6. ทุกองค์ประกอบโต้ตอบต้องใช้คีย์บอร์ดได้ มี focus ที่มองเห็น พื้นที่กด ≥40px
7. ข้อความภาษาไทยใช้ line-height ≥1.5 และห้ามตัดคำกลางพยางค์ด้วย `word-break: break-all`
8. ห้ามสร้างคอมโพเนนต์ซ้ำ ค้นหาในโค้ดก่อน ถ้าต้องเพิ่มให้เขียนลงเอกสารนี้ก่อน
9. ห้ามติดตั้งไลบรารีเพิ่ม (เช่น animation) โดยไม่ผ่านเช็กลิสต์ 5 ข้อ (ติดตั้งแล้ว/เวอร์ชันเข้ากัน/ของเดิมทำได้ไหม/ขนาด/จำเป็นจริง) เริ่มต้นใช้ CSS ล้วน
10. ห้ามแก้ token หรือมาตรฐานคอมโพเนนต์เอง ต้องเสนอ → อนุมัติ → อัปเดตเอกสาร+`tokens.css`+Changelog พร้อมกัน
11. **เมื่อเชื่อมกับระบบตามแผน:** ไม่ย้ายกฎหรือ persistence มาไว้ใน UI · ใช้ JavaScript และ contracts ใน `restart/shapes.md` · แก้เฉพาะชั้นหน้าตาโดยไม่เปลี่ยน API หรือ engine เอง

ตรวจโค้ดด้วย `check_tokens.py` ของสกิล (จับ hex/ค่า arbitrary นอกไฟล์ token) ก่อนบอกว่างานเสร็จ
